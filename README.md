# Kisan Setu (Farmer's Bridge) 🌾🚛

**Kisan Setu** is a zero-commission, vehicle booking portal that directly connects rural Indian farmers with nearby transporters. Farmers can book crop transport to the nearest mandi without brokers or hidden fees, ensuring transparency and fair pricing.

## 🚀 Features

- **Zero Commission**: No brokers, no hidden fees. Farmers pay exactly what transporters earn.
- **Farmer Dashboard**: Track live trips, view mandi rates, check weather, and find nearby transporters.
- **Transporter Dashboard**: Accept trip requests, track active trips, view earnings, and manage history.
- **Book a Trip**: A simple 3-step booking process to connect farmers with transporters instantly.
- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop devices.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite 5
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Language**: JavaScript (JSX)

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/kisan-setu.git
   cd kisan-setu
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.
